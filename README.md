# ELDIA

ELDIA is a compact 2D/2.5D cyberpunk pixel-art prototype for GAMEATHON 8.0, themed around **The Matrix: Break the Simulation**.

## Current setup

- Unity Editor: `6000.6.6f1`
- Template: `com.unity.template.2d`
- Render pipeline: Built-In Render Pipeline
- Input backend: Legacy Input Manager (`activeInputHandler: 0`)
- Repository branch: `feat/hari-core`

Phase 2 establishes the Unity project baseline only. Gameplay systems are not implemented yet.

## Open project

Open this directory with Unity `6000.6.6f1`:

```text
/home/hari007/Projects/Academics/Hackathons/Eldia
```

Generated Unity folders such as `Library/`, `Temp/`, `Obj/`, `Logs/`, and build output are excluded from Git.
